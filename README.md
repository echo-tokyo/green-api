Тестовое задание Green Api.

Используется Zustand для хранения сообщений и уведомлений, сверх ТЗ функциональности нет.
ИИ использовалось минимально, для рутинных и базовых задач.

Деплой: https://green-api-eight-inky.vercel.app/
GitHub: https://github.com/echo-tokyo/green-api

## Предварительная настройка

1. Инстанс Telegram должен быть авторизован в [личном кабинете](https://console.green-api.com)
2. В настройках инстанса нужно включить "Получать уведомления о входящих сообщениях и файлах"
3. Желательно выключить VPN, если не будет соединения
4. Проверить, что номера в telegram не скрыты в настройках конфиденциальности

## Локальный запуск

Требуется Node.js `^20.19.0` или `>=22.12.0`.

```bash
npm install
npm run dev
```
